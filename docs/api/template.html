create

POST /whatsapp/v2/templates

Authentication: oauth2 (Bearer).

Request body

application/json

Property Type Required Description
allow_category_change boolean No Set to true to allow to assign a category based on template guidelines and the template's contents. This can prevent the template status from immediately being set to REJECTED upon creation due to miscategorization. If omitted, template will not be auto-assigned a category and its status may be set to REJECTED if determined to be miscategorized.
category enum: AUTHENTICATION, MARKETING, UTILITY Yes
components array of object Yes Array of components that make up the template.
components[].buttons array,null No Button components to be used in the template.
components[].examples object No
components[].examples.body_text array,null No Body text
components[].examples.header_handle array,null No Header handle
components[].examples.header_text array,null No Header text
components[].format enum: TEXT, IMAGE, DOCUMENT, VIDEO, LOCATION No
components[].text string,null No Component text. Required for components with type HEADER, BODY or FOOTER.
components[].type enum: GREETING, HEADER, BODY, FOOTER, BUTTONS, CAROUSEL, ... No
language enum: af, sq, ar, az, bn, bg, ... Yes
library_template_body_inputs object No
library_template_body_inputs.add_contact_number boolean No Add contact number
library_template_body_inputs.add_learn_more_link boolean No Add learn more link
library_template_body_inputs.add_security_recommendation boolean No Add security recommendation
library_template_body_inputs.add_track_package_link boolean No Add track package link
library_template_body_inputs.code_expiration_minutes integer (int64) No Code expiration minutes
library_template_button_inputs array,null No Optional data during creation of a template from a library template. These are optional fields for the button component.
library_template_name string,null No Library template name
message_send_ttl_seconds integer (int64) No Time to live for message template sent. If users are offline for more than TTL duration after message template is sent, we will retry the delivery for a period of time known as a time-to-live, TTL, or the message validity period. TTL can be configured for certain message types.
name string Yes Template name
parameter_format enum: NAMED, POSITIONAL No
sub_category enum: ORDER_DETAILS, ORDER_STATUS No
